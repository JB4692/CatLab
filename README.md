# Cat Lab
Senior Project - Spring 2025

CatLab is a 2D platformer where users can create and play levels of their own creation using real world objects to create the game board. We aim to create an interactive experience for players to play with groups in order to challenge each other to play through custom levels. The overall goal of the game is to traverse the level that you have created and get to the end point, which is a litter box within the allotted time frame.
